# Keyboard Shortcuts

**Status:** Proposed  
**Audience:** All users, frontend engineers  
**Last Reviewed:** 2024-01-15

> `Cmd` refers to the Command key on macOS. `Ctrl` is used on Windows/Linux. Shortcuts shown as `Ctrl/Cmd` apply to both.

---

## Global Shortcuts

| Action | Windows/Linux | macOS |
|--------|--------------|-------|
| Undo | `Ctrl+Z` | `Cmd+Z` |
| Redo | `Ctrl+Shift+Z` or `Ctrl+Y` | `Cmd+Shift+Z` |
| Cut | `Ctrl+X` | `Cmd+X` |
| Copy | `Ctrl+C` | `Cmd+C` |
| Paste | `Ctrl+V` | `Cmd+V` |
| Paste in Place | `Ctrl+Shift+V` | `Cmd+Shift+V` |
| Duplicate | `Ctrl+D` | `Cmd+D` |
| Select All | `Ctrl+A` | `Cmd+A` |
| Delete | `Delete` or `Backspace` | `Delete` or `Backspace` |
| Save (manual) | `Ctrl+S` | `Cmd+S` |
| Open board | `Ctrl+O` | `Cmd+O` |
| New board | `Ctrl+N` | `Cmd+N` |
| Search (board objects) | `Ctrl+F` | `Cmd+F` |
| Open AI Panel | `Ctrl+/` | `Cmd+/` |
| Keyboard shortcut reference | `?` | `?` |

## Canvas Navigation

| Action | Shortcut |
|--------|----------|
| Pan (while any tool active) | `Space + Drag` |
| Zoom in | `Ctrl/Cmd + =` or `Ctrl/Cmd + Scroll Up` |
| Zoom out | `Ctrl/Cmd + -` or `Ctrl/Cmd + Scroll Down` |
| Zoom to 100% | `Ctrl/Cmd + 0` |
| Fit all content | `Ctrl/Cmd + Shift + H` or `Ctrl/Cmd + 1` |
| Fit selection | `Ctrl/Cmd + 2` |
| Toggle minimap | `M` |
| Toggle rulers | `Ctrl/Cmd + R` |
| Toggle grid | `Ctrl/Cmd + '` |
| Toggle snap to grid | `Ctrl/Cmd + Shift + '` |

## Object Manipulation

| Action | Shortcut |
|--------|----------|
| Move object (1px) | Arrow keys |
| Move object (10px) | `Shift + Arrow` |
| Resize proportionally | Hold `Shift` while dragging handle |
| Resize from centre | Hold `Alt/Option` while dragging handle |
| Lock aspect ratio (during resize) | Hold `Shift` |
| Rotate 45° increments | Hold `Shift` while rotating |
| Enter edit mode (text/shape) | `Enter` or double-click |
| Exit edit mode | `Escape` |
| Group selection | `Ctrl/Cmd + G` |
| Ungroup | `Ctrl/Cmd + Shift + G` |
| Lock object | `Ctrl/Cmd + Shift + L` |
| Unlock object | `Ctrl/Cmd + Shift + L` |

| Action | Shortcut |
|--------|----------|

## Algorithm Lab (Workspace-Specific)

| Action | Shortcut |
|--------|----------|
| Play / Pause algorithm | `Space` |
| Step forward | `→` (Right arrow, when paused) |
| Step backward | `←` (Left arrow, when paused) |
| Reset to start | `Ctrl/Cmd + Shift + R` |
| Increase playback speed | `Shift + →` |
| Decrease playback speed | `Shift + ←` |
| Add node | `N` |
| Add edge (click two nodes) | `E` then click source, then target |

## Collaboration Mode

| Action | Shortcut |
|--------|----------|
| Toggle cursor visibility | `Ctrl/Cmd + Shift + C` |
| Follow presenter | `Ctrl/Cmd + Shift + F` |
| Leave follow mode | `Escape` |
| Open comments | `Ctrl/Cmd + Shift + M` |
| Add comment at cursor | `C` (when in comment mode) |

## Customization (Planned — Phase 2)

Keyboard shortcuts will be customizable via Settings → Keyboard. Custom bindings persist per user account. Conflicts are detected and flagged during assignment.
